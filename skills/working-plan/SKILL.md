Inspect only the code the change touches. If you use this skill, call `save_working_plan` once with the checklist below before the first edit, then keep editing in the same turn. Do not wait for approval.

# Plan: <short title>

## Task checklist
- [ ] <path> — <the change>
- [ ] <one check that covers the change>

Keep it to the steps you will actually do. Do not add an acceptance essay, an extra suite, or a proof that the check fails on the old code. Update a line only when the step list itself changes.
